# 스테이지별 배경/BGM/특수효과 시스템 가이드

## ?? 개요
스테이지별로 다른 배경, BGM, 특수효과를 설정하고 관리하는 시스템입니다.

## ??? 파일 구조

### 1. YaCht_StageData.cs
스테이지별 리소스 데이터 구조체
```csharp
public struct YaCht_StageData
{
    public int m_stageNumber;                   // 스테이지 번호 (1~12)
    public int m_chapterNumber;                 // 챕터 번호 (1~3)
    public string m_backgroundResourcePath;     // 배경 이미지 경로
    public string m_bgmResourcePath;            // BGM 경로
    public string m_specialEffectResourcePath;  // 특수 효과 경로
    public bool m_isBossStage;                  // 보스 스테이지 여부
    public string m_stageDescription;           // 스테이지 설명
}
```

### 2. YaCht_StageDatabase.cs
스테이지 리소스를 관리하는 정적 데이터베이스

```csharp

        if (effectPrefab != null)

            // 특수 효과 인스턴스 생성
            GameObject effectInstance = Instantiate(effectPrefab, targetPosition, Quaternion.identity);
        }
    }
}
```

## ?? GameScene에서 사용 예시

```csharp
using UnityEngine;
using UnityEngine.UI;

public class YaCht_GameScene : MonoBehaviour
{
    [SerializeField] private Image backgroundImage;
    [SerializeField] private AudioSource bgmAudioSource;
    [SerializeField] private Transform effectSpawnPoint;
    [SerializeField] private YaCht_WWEMainGame wwe;
    
    void Start()
    {
        // 현재 스테이지 정보 가져오기
        int currentStage = YaCht_GameManager.StageManager.CurrentStageNumber;
        YaCht_StageData stageData = YaCht_StageDatabase.GetStageData(currentStage);
        
        // 배경 설정
        LoadBackground(stageData.m_backgroundResourcePath);
        
        // BGM 재생
        PlayBGM(stageData.m_bgmResourcePath);
        
        // 보스전이면 특수 효과 생성
        if (stageData.m_isBossStage && !string.IsNullOrEmpty(stageData.m_specialEffectResourcePath))
        {
            SpawnSpecialEffect(stageData.m_specialEffectResourcePath);
        }
        
        // 기존 게임 로직
        if (YaCht_GameManager.StageManager != null)
        {
            if (YaCht_GameManager.StageManager.CurrentStageNumber == 1 && 
                YaCht_GameManager.StageManager.CurrentEnemyHealth <= 0)
            {
                YaCht_GameManager.StartNewStage(1);
            }
            
            YaCht_GameManager.enemyHealth = YaCht_GameManager.StageManager.CurrentEnemyHealth;
            YaCht_GameManager.enemyMaxHealth = YaCht_GameManager.StageManager.CurrentEnemy.m_maxHealth;
        }
        
        YaCht_GameManager.CardManager.StartGame();
        wwe.Init();
        
        Debug.Log($"[GameScene] 스테이지 {currentStage} 시작 - {stageData.m_stageDescription}");
    }
    
    private void LoadBackground(string path)
    {
        Sprite backgroundSprite = Resources.Load<Sprite>(path);
        
        if (backgroundSprite != null && backgroundImage != null)
        {
            backgroundImage.sprite = backgroundSprite;
            Debug.Log($"배경 로드 완료: {path}");
        }
        else
        {
            Debug.LogWarning($"배경을 찾을 수 없습니다: {path}");
        }
    }
    
    private void PlayBGM(string path)
    {
        AudioClip bgmClip = Resources.Load<AudioClip>(path);
        
        if (bgmClip != null && bgmAudioSource != null)
        {
            bgmAudioSource.clip = bgmClip;
            bgmAudioSource.loop = true;
            bgmAudioSource.Play();
            Debug.Log($"BGM 재생 시작: {path}");
        }
        else
        {
            Debug.LogWarning($"BGM을 찾을 수 없습니다: {path}");
        }
    }
    
    private void SpawnSpecialEffect(string path)
    {
        GameObject effectPrefab = Resources.Load<GameObject>(path);
        
        if (effectPrefab != null && effectSpawnPoint != null)
        {
            GameObject effectInstance = Instantiate(effectPrefab, effectSpawnPoint.position, Quaternion.identity);
            effectInstance.transform.SetParent(effectSpawnPoint);
            Debug.Log($"특수 효과 생성: {path}");
        }
        else
        {
            Debug.LogWarning($"특수 효과를 찾을 수 없습니다: {path}");
        }
    }
}
```

## ?? 주의사항

1. **리소스 경로**: 모든 리소스는 `Resources` 폴더 안에 있어야 합니다
2. **경로 형식**: `Resources.Load`는 파일 확장자를 제외한 경로를 사용합니다
   - ? `"Sprites/Backgrounds/Chapter1/Stage1"`
   - ? `"Sprites/Backgrounds/Chapter1/Stage1.png"`
3. **초기화**: `YaCht_StageDatabase`는 게임 시작 시 자동으로 초기화됩니다
4. **특수 효과**: 선택사항이므로 빈 문자열(`""`)이어도 됩니다

## ?? 기존 시스템과의 연동

### YaCht_EnemyDatabase와의 관계
- `YaCht_EnemyDatabase`: 적의 정보 (이름, 체력, 스프라이트)
- `YaCht_StageDatabase`: 스테이지 환경 (배경, BGM, 효과)
- 두 시스템은 `stageNumber`로 연결됩니다

### YaCht_StageManager 활용
```csharp
// 현재 스테이지 번호로 리소스 가져오기
```
